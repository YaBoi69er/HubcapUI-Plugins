## RenoDX

- **Many more supported games.** Games covered by the generic Unreal Engine RenoDX mod are detected again, including the new Unreal Engine Extended mod (for example STAR WARS: Galactic Racer). Games listed only for the legacy Unreal mod still work, and the Extended version is preferred when a game appears in both.
- **Know what you're installing.** The install dialog shows whether the mod is made for that game or is a generic engine mod, and which add-on file it uses.
- **Clear setup steps.** The install dialog and result now list what Hubcap does for you, what you still need to do, and what to try if HDR doesn't work.
- **Automatic Engine.ini setup.** For Unreal games that need it, Hubcap adds the HDR settings to the game's Engine.ini and makes it read-only. Your original Engine.ini is restored when RenoDX is removed. If the game hasn't been launched yet, Hubcap uses the usual Unreal location and moves the settings after the first launch if the game uses a different folder.
- **Upgrade Path set for you.** Hubcap sets the Unreal Engine Extended Upgrade Path (On or Off) that the RenoDX wiki lists for each game.
- **Fixes:** deprecated mods and related non-RenoDX mods are no longer offered, and Source Engine games no longer receive the Unity add-on.

## OptiScaler

- No changes; version updated to match the release.

Updates install automatically on Hubcap builds with plugin auto-updates turned on, the next time Steam starts. If you are upgrading from v0.1.1, replace the plugin DLLs manually once to switch to the renamed update source.
